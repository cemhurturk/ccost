# ccost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a zero-dependency CLI that reconstructs the API-equivalent dollar cost of past Claude Code sessions from `~/.claude/projects` transcripts and compares it against a fixed monthly subscription price.

**Architecture:** Single-pass, stateless scan. `cli` walks the transcript tree via `transcript.scan()`, which yields deduplicated `Record`s; `aggregate` groups them into buckets and prices each via `pricing.cost()`; `report` renders a table or JSON. No cache, no database, no network. `pricing`, `aggregate`, and `report` are pure and touch no filesystem.

**Tech Stack:** Python 3.9.6 (system interpreter), stdlib only — `json`, `pathlib`, `argparse`, `decimal`, `datetime`, `collections`. Tests are stdlib `unittest`.

**Spec:** `docs/superpowers/specs/2026-07-25-claude-code-usage-cost-calculator-design.md`

## Global Constraints

- **Python 3.9.6 is the floor.** No `match`, no `X | Y` union syntax at runtime, no `tomllib`. Use `typing.Optional` / `typing.Tuple` / `typing.Dict` in annotations.
- **`datetime.fromisoformat` in 3.9 does NOT parse a trailing `Z`.** Every timestamp parse must do `ts.replace("Z", "+00:00")` first. This is the single most likely runtime bug in this codebase.
- **Zero third-party dependencies.** No pytest, no requests, no venv. If a task seems to need a package, it does not.
- **All money is `Decimal`.** Never `float`. Rounding to cents happens once, at render time, `ROUND_HALF_UP`.
- **Tests run as** `python3 -m unittest discover -s tests -t . -v` from the repo root.
- **Commits are two separate commands** — `git add <paths>` then `git commit -m "..."`. A chained `git add && git commit` is rejected by the security gate. The gate may also require a scan attestation before the commit lands; if the attest command is blocked, report it and leave the commit pending rather than working around it.
- **Never write to `~/.claude/`.** This tool is strictly read-only against the transcript tree.

```python
"""Rate table and cost arithmetic. Pure: no filesystem, no network.

Rates captured 2026-07-25 from the Anthropic pricing reference, in USD per
million tokens. Update the RATES table by hand when pricing changes.
"""
from datetime import date
from decimal import Decimal
from typing import Dict, Optional, Tuple

# Bare aliases appear in some transcripts. They resolved to whatever was
# current when the message was written, which may differ from today's model
# in that tier. Known approximation; see spec section 4.
ALIASES = {
    "opus": "claude-opus-5",
    "sonnet": "claude-sonnet-5",
    "haiku": "claude-haiku-4-5",
}

# Harness-generated pseudo-models. Never charged; dollars are known to be zero.
NON_BILLABLE = {"<synthetic>"}

# model -> (input $/MTok, output $/MTok)
RATES: Dict[str, Tuple[Decimal, Decimal]] = {
    "claude-fable-5": (Decimal("10"), Decimal("50")),
    "claude-mythos-5": (Decimal("10"), Decimal("50")),
    "claude-opus-5": (Decimal("5"), Decimal("25")),
    "claude-opus-4-8": (Decimal("5"), Decimal("25")),
    "claude-opus-4-7": (Decimal("5"), Decimal("25")),
    "claude-opus-4-6": (Decimal("5"), Decimal("25")),
    "claude-sonnet-5": (Decimal("3"), Decimal("15")),
    "claude-sonnet-4-6": (Decimal("3"), Decimal("15")),
    "claude-haiku-4-5": (Decimal("1"), Decimal("5")),
    "claude-haiku-4-5-20251001": (Decimal("1"), Decimal("5")),
}

# Fast mode runs the same model at premium rates.
FAST_RATES: Dict[str, Tuple[Decimal, Decimal]] = {
    "claude-opus-5": (Decimal("10"), Decimal("50")),
    "claude-opus-4-8": (Decimal("10"), Decimal("50")),
}

# Sonnet 5 introductory pricing, inclusive of the end date.
SONNET_5_INTRO_END = date(2026, 8, 31)
SONNET_5_INTRO = (Decimal("2"), Decimal("10"))

# Multipliers on the model's INPUT rate.
CACHE_READ = Decimal("0.1")
CACHE_WRITE_5M = Decimal("1.25")
CACHE_WRITE_1H = Decimal("2")

MILLION = Decimal("1000000")


def canonical(model: str) -> str:
    """Resolve a bare tier alias to a full model id."""
    return ALIASES.get(model, model)


def is_billable(model: str) -> bool:
    return canonical(model) not in NON_BILLABLE


def rates_for(model, speed, on_date):
    # type: (str, str, date) -> Optional[Tuple[Decimal, Decimal]]
    """Return (input, output) $/MTok, or None if the model has no known rate."""
    name = canonical(model)
    if name in NON_BILLABLE:
        return None
    if speed == "fast" and name in FAST_RATES:
        return FAST_RATES[name]
    if name == "claude-sonnet-5" and on_date <= SONNET_5_INTRO_END:
        return SONNET_5_INTRO
    return RATES.get(name)


def cost(model, speed, on_date, input_tokens, output_tokens,
         cache_read, cache_write_5m, cache_write_1h):
    # type: (...) -> Optional[Decimal]
    """Dollar cost of one message. None if the model has no known rate."""
    if not is_billable(model):
        return Decimal("0")
    rates = rates_for(model, speed, on_date)
    if rates is None:
        return None
    rate_in, rate_out = rates
    units = (
        Decimal(input_tokens) * rate_in
        + Decimal(output_tokens) * rate_out
        + Decimal(cache_read) * rate_in * CACHE_READ
        + Decimal(cache_write_5m) * rate_in * CACHE_WRITE_5M
        + Decimal(cache_write_1h) * rate_in * CACHE_WRITE_1H
    )
    return units / MILLION
```

```python
"""Walk the Claude Code transcript tree and yield deduplicated usage records.

Read-only. Never writes to the transcript directory.
"""
import json
from collections import namedtuple
from datetime import datetime
from typing import List, Optional, Tuple

Record = namedtuple(
    "Record",
    "ts project session model speed "
    "input output cache_read cache_write_5m cache_write_1h",
)


class ScanStats(object):
    def __init__(self):
        self.files_scanned = 0
        self.files_unreadable = 0
        self.lines_skipped = 0
        self.duplicates_dropped = 0


def display_project(slug):
    # type: (str) -> str
    """Strip a leading -Users-<name>- prefix from a project slug for display."""
    parts = slug.split("-")
    # slug starts with an empty part because of the leading dash
    if len(parts) >= 3 and parts[0] == "" and parts[1] == "Users":
        return "-".join(parts[3:]) or slug
    return slug


def dedup_key(obj):
    # type: (dict) -> str
    """One API response spans several transcript lines, each repeating the
    same cumulative usage. This key collapses them."""
    return "%s|%s" % (obj.get("message", {}).get("id"), obj.get("requestId"))


def _parse_ts(raw):
    # type: (Optional[str]) -> Optional[datetime]
    if not raw:
        return None
    # Python 3.9's fromisoformat cannot parse a trailing "Z".
    try:
        return datetime.fromisoformat(raw.replace("Z", "+00:00"))
    except ValueError:
        return None


def record_from(obj, project):
    # type: (dict, str) -> Optional[Record]
    if obj.get("type") != "assistant":
        return None
    message = obj.get("message") or {}
    usage = message.get("usage")
    if not usage:
        return None
    ts = _parse_ts(obj.get("timestamp"))
    if ts is None:
        return None
    creation = usage.get("cache_creation") or {}
    return Record(
        ts=ts,
        project=project,
        session=obj.get("sessionId") or "",
        model=message.get("model") or "",
        speed=usage.get("speed") or "standard",
        input=int(usage.get("input_tokens") or 0),
        output=int(usage.get("output_tokens") or 0),
        cache_read=int(usage.get("cache_read_input_tokens") or 0),
        cache_write_5m=int(creation.get("ephemeral_5m_input_tokens") or 0),
        cache_write_1h=int(creation.get("ephemeral_1h_input_tokens") or 0),
    )


def scan(root):
    # type: (object) -> Tuple[List[Record], ScanStats]
    """Scan every .jsonl under root. Returns (records, stats)."""
    stats = ScanStats()
    records = []  # type: List[Record]
    seen = set()

    if not root.exists():
        return records, stats

    for path in sorted(root.rglob("*.jsonl")):
        try:
            relative = path.relative_to(root)
        except ValueError:
            continue
        # Project is the FIRST path component: one project dir nests another
        # project slug inside it, so a last-component rule misattributes.
        project = relative.parts[0]
        try:
            handle = path.open("r", errors="replace")
        except OSError:
            stats.files_unreadable += 1
            continue
        stats.files_scanned += 1
        with handle:
            for line in handle:
                # Cheap reject before any JSON parsing. This is what makes a
                # full 1.4 GB scan take seconds. It cannot change results:
                # a row with no "usage" key is not billable.
                if '"usage"' not in line:
                    continue
                try:
                    obj = json.loads(line)
                except ValueError:
                    stats.lines_skipped += 1
                    continue
                if not isinstance(obj, dict):
                    continue
                record = record_from(obj, project)
                if record is None:
                    continue
                key = dedup_key(obj)
                if key in seen:
                    stats.duplicates_dropped += 1
                    continue
                seen.add(key)
                records.append(record)

    return records, stats
```

```python
"""Group records into priced buckets. Pure: no filesystem, no network."""
from collections import namedtuple
from decimal import Decimal
from typing import Dict, List

from ccost import pricing
from ccost.transcript import display_project

Bucket = namedtuple("Bucket", "key input output cache_read cache_write cost")
ModelTally = namedtuple("ModelTally", "tokens rows")
Result = namedtuple("Result", "buckets unpriced non_billable")


def month_of(record):
    """Local-time month. 'What did July cost me' is a wall-clock question."""
    return record.ts.astimezone().strftime("%Y-%m")


def bucket_key(record, by):
    if by == "month":
        return month_of(record)
    if by == "model":
        return pricing.canonical(record.model)
    if by == "project":
        return display_project(record.project)
    raise ValueError("unknown grouping: %r" % (by,))


def _tally(store, model, tokens):
    previous = store.get(model, ModelTally(0, 0))
    store[model] = ModelTally(previous.tokens + tokens, previous.rows + 1)


def aggregate(records, by="month"):
    totals = {}  # type: Dict[str, List]
    unpriced = {}  # type: Dict[str, ModelTally]
    non_billable = {}  # type: Dict[str, ModelTally]

    for record in records:
        key = bucket_key(record, by)
        if key not in totals:
            totals[key] = [0, 0, 0, 0, Decimal("0")]
        slot = totals[key]
        slot[0] += record.input
        slot[1] += record.output
        slot[2] += record.cache_read
        slot[3] += record.cache_write_5m + record.cache_write_1h

        tokens = (record.input + record.output + record.cache_read
                  + record.cache_write_5m + record.cache_write_1h)

        if not pricing.is_billable(record.model):
            _tally(non_billable, record.model, tokens)
            continue

        amount = pricing.cost(
            record.model, record.speed, record.ts.astimezone().date(),
            record.input, record.output, record.cache_read,
            record.cache_write_5m, record.cache_write_1h,
        )
        if amount is None:
            # Unknown model: tokens counted, dollars unknown and excluded.
            _tally(unpriced, record.model, tokens)
            continue
        slot[4] += amount

    buckets = [
        Bucket(key, v[0], v[1], v[2], v[3], v[4])
        for key, v in sorted(totals.items())
    ]
    return Result(buckets=buckets, unpriced=unpriced, non_billable=non_billable)
```

```python
"""Render aggregate results. Pure: no filesystem, no network."""
import json
from decimal import Decimal, ROUND_HALF_UP

CENTS = Decimal("0.01")


def human_tokens(n):
    if n >= 1_000_000:
        return "%.1fM" % (n / 1_000_000.0)
    if n >= 1_000:
        return "%.1fK" % (n / 1_000.0)
    return str(n)


def money(value):
    quantized = Decimal(value).quantize(CENTS, rounding=ROUND_HALF_UP)
    return "${:,.2f}".format(quantized)


def _total(result):
    total = Decimal("0")
    for bucket in result.buckets:
        total += bucket.cost
    return total


def render_table(result, plan_usd, current_month, stats, elapsed):
    lines = []
    lines.append("Claude Code usage — API-equivalent cost")
    lines.append("%d transcripts · scanned in %.1fs" % (stats.files_scanned, elapsed))
    lines.append("")

    if not result.buckets:
        lines.append("No usage found.")
        return "\n".join(lines)

    show_plan = plan_usd is not None
    header = "%-10s %9s %9s %10s %10s %12s" % (
        "PERIOD", "INPUT", "OUTPUT", "CACHE-R", "CACHE-W", "API-EQUIV")
    if show_plan:
        header += " %7s %9s" % ("PLAN", "MULTIPLE")
    lines.append(header)

    for bucket in result.buckets:
        label = bucket.key
        if current_month is not None and bucket.key == current_month:
            label += "*"
        row = "%-10s %9s %9s %10s %10s %12s" % (
            label,
            human_tokens(bucket.input), human_tokens(bucket.output),
            human_tokens(bucket.cache_read), human_tokens(bucket.cache_write),
            money(bucket.cost),
        )
        if show_plan:
            multiple = bucket.cost / plan_usd if plan_usd else Decimal("0")
            row += " %7s %8.1fx" % (money(plan_usd), multiple)
        lines.append(row)

    total = _total(result)
    total_row = "%-10s %9s %9s %10s %10s %12s" % (
        "TOTAL", "", "", "", "", money(total))
    if show_plan:
        plan_total = plan_usd * len(result.buckets)
        multiple = total / plan_total if plan_total else Decimal("0")
        total_row += " %7s %8.1fx" % (money(plan_total), multiple)
    lines.append(total_row)

    if result.unpriced:
        lines.append("")
        lines.append("Unpriced — no published rate, dollars unknown and excluded:")
        for model in sorted(result.unpriced):
            tally = result.unpriced[model]
            lines.append("  %-28s %10s tokens  (%d rows)"
                         % (model, human_tokens(tally.tokens), tally.rows))

    if result.non_billable:
        lines.append("")
        lines.append("Non-billable — known to cost zero:")
        for model in sorted(result.non_billable):
            tally = result.non_billable[model]
            lines.append("  %-28s %10s tokens  (%d rows)"
                         % (model, human_tokens(tally.tokens), tally.rows))

    if stats.lines_skipped or stats.files_unreadable:
        lines.append("")
        lines.append("Skipped: %d unparseable lines, %d unreadable files"
                     % (stats.lines_skipped, stats.files_unreadable))

    if current_month is not None:
        lines.append("")
        lines.append("* partial month")

    return "\n".join(lines)


def render_json(result, plan_usd):
    payload = {
        "buckets": [
            {
                "key": b.key,
                "input_tokens": b.input,
                "output_tokens": b.output,
                "cache_read_tokens": b.cache_read,
                "cache_write_tokens": b.cache_write,
                "cost_usd": str(Decimal(b.cost).quantize(CENTS,
                                                         rounding=ROUND_HALF_UP)),
            }
            for b in result.buckets
        ],
        "total_usd": str(_total(result).quantize(CENTS, rounding=ROUND_HALF_UP)),
        "plan_usd_per_month": str(plan_usd) if plan_usd is not None else None,
        "unpriced": {m: {"tokens": t.tokens, "rows": t.rows}
                     for m, t in result.unpriced.items()},
        "non_billable": {m: {"tokens": t.tokens, "rows": t.rows}
                         for m, t in result.non_billable.items()},
    }
    return json.dumps(payload, indent=2, sort_keys=True)
```

```python
                        default="month", help="how to group results")
    parser.add_argument("--since", metavar="YYYY-MM",
                        help="ignore activity before this month (local time)")
    parser.add_argument("--project", metavar="SLUG",
                        help="restrict to one project directory name")
    parser.add_argument("--json", action="store_true",
                        help="emit machine-readable JSON")
    parser.add_argument("--plan-usd", metavar="N",
                        help="monthly subscription price; overrides the config")
    parser.add_argument("--root", metavar="PATH", default=str(DEFAULT_ROOT),
                        help="transcript root (default: ~/.claude/projects)")
    parser.add_argument("--config", metavar="PATH", default=str(DEFAULT_CONFIG),
                        help="config file (default: ~/.config/ccost/config.json)")
    return parser


def main(argv=None):
    args = build_parser().parse_args(argv)

    plan_usd = None
    if args.plan_usd is not None:
        try:
            plan_usd = Decimal(args.plan_usd)
        except InvalidOperation:
            plan_usd = None
    else:
        plan_usd = load_plan_usd(Path(args.config))

    started = time.time()
    records, stats = transcript_module.scan(Path(args.root))
    elapsed = time.time() - started

    if args.project:
        records = [r for r in records if r.project == args.project]
    if args.since:
        records = [r for r in records
                   if aggregate_module.month_of(r) >= args.since]

    result = aggregate_module.aggregate(records, by=args.by)

    if args.json:
        print(report_module.render_json(result, plan_usd))
        return 0

    current_month = None
    if args.by == "month":
        current_month = datetime.now().astimezone().strftime("%Y-%m")
    print(report_module.render_table(result, plan_usd, current_month,
                                     stats, elapsed))
    return 0
```

```markdown
# ccost

Reconstructs the API-equivalent dollar cost of past Claude Code sessions from
the transcripts in `~/.claude/projects`.

Claude Code records token counts, not costs — the live figure the statusline
shows is discarded when a session ends. On a subscription plan real spend is
fixed, so the number here is notional: what the same usage would have cost at
API list prices. Compared against a monthly plan price, that is a value check.

## Usage

    python3 -m ccost                      # monthly breakdown
    python3 -m ccost --by project         # per-project
    python3 -m ccost --by model           # per-model
    python3 -m ccost --since 2026-06      # recent months only
    python3 -m ccost --json               # machine-readable

Set the plan price once, in `~/.config/ccost/config.json`:

    { "plan_usd_per_month": 200 }

Or pass `--plan-usd 200`. Without either, the plan comparison is omitted.

## Requirements

Python 3.9+. No third-party dependencies.

## Tests

    python3 -m unittest discover -s tests -t . -v

## Accuracy notes

- Rates are captured 2026-07-25 and edited by hand in `ccost/pricing.py`.
- Models with no published rate contribute tokens but not dollars, and are
  listed under the table rather than silently counted as zero.
- Bare model aliases (`opus`, `sonnet`, `haiku`) resolve to today's model in
  that tier, which may differ from what they resolved to when written.
- This tool only reads. It never writes to `~/.claude/`.
```
